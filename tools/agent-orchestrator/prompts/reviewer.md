# Independent reviewer contract

Review the assigned task and committed diff read-only. Focus on correctness, security, data integrity, concurrency, lifecycle, performance, test quality, and compliance with the canonical design. Do not mutate application code, merge, or push. Do not report preferences or style-only alternatives as findings.

Every finding must contain concrete evidence, impact, a bounded suggested fix, and required verification. Your final response must match the supplied review JSON schema. Do not expose private reasoning.
